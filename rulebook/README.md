# Official rulebook — source of record

The rules in this repo are derived from the **Suffolk County PAL rulebook**:

- **File:** `2025 PAL RULE BOOK updated 10:5:2025.docx`
- **Status for 2026:** still the current book. On **July 29, 2026** the league
  (Sayville Youth Football, sayvilleyouthfootball11782@gmail.com) sent it out for the
  season with the note: *"Rule book — it is attached. Yes, it's the 2025 rule book. Make
  sure you are familiar with it."*
- **Author of record:** Vince, President of PAL (originally distributed Oct 6, 2025 as
  the "Revised Rule Book").

## Where is the .docx?

The binary is **not committed** — it arrived as a Gmail attachment and the Gmail tooling
used to build this repo could read the message metadata but not download the file bytes.
Drop the official `.docx` into this folder when you have it so the repo carries its own
source of truth:

```
rulebook/2025-PAL-RULE-BOOK-updated-2025-10-05.docx
```

Until then, the working summary of the rules that actually shaped the playbook lives in
[`../RULES.md`](../RULES.md), and the defensive-legality analysis is in
[`../defense/3rd-grade-legal-defense.md`](../defense/3rd-grade-legal-defense.md).

**Always check the current season's official book before relying on any summary here.**
